### Install correctly

1. Right-click the downloaded ZIP and choose **Extract All**.
2. Open Raidex only from the extracted folder.
3. Keep the **Engine** and **Assets** folders beside **Raidex CoC Automation.exe**.
4. If the Engine folder disappears, check **Windows Security > Virus & threat protection > Protection history**, then download a fresh official copy.
